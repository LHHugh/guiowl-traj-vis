# 车机界面多步操作 · 按轨迹逐步点击结果

对 111 条操作轨迹、共 817 个步骤，逐条列出每一步的点击结果，并自动标注每条轨迹中出问题的步骤。

在线浏览：`index.html`（自包含页面，无外部依赖）

## 页面怎么看

- **绿点 + 十字** = GT 真实点击点
- **红点 + 十字** = 模型预测点
- **黄线** = 两点距离，中点标注像素距离
- **绿色线段** = GT 滑动（swipe）的起点 → 终点轨迹
- **灰点** = 末帧的 GT 点（该帧语义上应输出 terminate，不作为点击目标）
- **边框颜色** = 该步是否命中：绿 = 命中（≤5% 对角线）／红 = 未命中／青 = 末帧正确停止

## 页面结构

1. **逐轨迹汇总表** —— 每行一条轨迹，列出各模型的点击命中率与「本模型问题步」编号，点任务名可跳转到明细
2. **各模型轨迹级汇总** —— 点击 @5%、轨迹全对、点击全对、点击+停止全对、swipe 步对、末帧停止对
3. **按轨迹逐步结果** —— 111 张卡片，每张含全部步骤的缩略图、其他模型在该步是否失败的小标签，以及自动生成的问题步说明

## 命名说明

- **本模型（本次评测）** 为本页评测对象
- **本项目 ep1 / ep2 / ep3** 为同一路线的早期阶段
- **基础模型 1 ~ 4** 为参与对比的若干基线模型（匿名编号）
